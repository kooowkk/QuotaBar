# QuotaBar 0.2.0 beta 1

Claude와 ChatGPT/Codex 계정의 현재·주간 사용 한도와 리셋까지 남은 시간을 한 번에 확인하는 macOS 메뉴바 앱입니다.

## 다운로드

Assets에서 `QuotaBar-0.2.0-beta.1-macOS-universal.zip`을 받으세요. `Source code` 파일은 직접 빌드하는 사람을 위한 코드입니다. 앱 ZIP을 아직 첨부하지 않았다면 이 안내로 게시하지 마세요.

## 요구 사항

- macOS 14 이상
- CodexBar 조회 도구
- 필요한 서비스의 Claude Code / Codex CLI와 본인 계정 로그인

## 이번 변경

연결 도우미, 설치 여부 확인, 공식 로그인 시작 버튼, 도구별 오류 안내, 공개용 문자 아이콘을 추가했습니다. 기본 5분 갱신과 현재·주간 사용률 표시를 유지합니다.

## 주의 및 한계

무료 비공증 배포본으로 macOS에서 첫 실행 허용이 필요할 수 있습니다. 외부 도구 설치·본인 계정 연결은 별도로 해야 합니다. 일반 ChatGPT 채팅 잔여 메시지 수나 정확한 토큰 개수를 표시하지 않습니다. 외부 도구·서비스 변경으로 조회가 실패할 수 있습니다. 공식 제공자의 앱이나 승인된 제휴 서비스가 아닙니다.
