# 이번 묶음의 검증 기록

2026-10-01, Linux 제작 환경.

완료:
- 설치·배포·로그인 스크립트의 `bash -n` 구문 검사.
- 문서의 저장소 내부 파일 링크 존재 여부 확인.
- 공개 파일의 일반적인 비밀 키 패턴·개인 맥 경로 검사.
- 참고 로고 PNG와 개인 계정·설정·빌드 결과 파일이 소스 묶음에 없는지 확인.
- macOS가 아닌 환경에서 빌드 스크립트가 명확한 안내와 함께 중단되는지 확인.
- 패키지 ZIP 파일 구성과 CRC 무결성 확인.

미실행:
- Swift 데이터 계산 테스트 및 SwiftUI 컴파일: swiftc/macOS SDK 없음.
- 실제 맥에서 새 연결 도우미 표시와 로그인 버튼 실행.
- Apple Silicon/Intel Universal 빌드 및 각각의 맥 실행.
- 실제 계정 사용량 조회, 5분 반복 갱신, 잠자기·로그인 자동 실행.

데이터 계산 테스트는 Install.command와 Build-Release.command에서 빌드 전에 실행됩니다. 새 ChatGPT 기본 항목이 Codex를 조회하도록 하는 회귀 검사를 추가했습니다. 테스트를 작성한 것과 통과한 것은 구분합니다. 실제 공개 전 docs/RELEASE-CHECKLIST.md를 사용하세요.

위 패턴 검사는 모든 비밀 정보나 저작권 문제를 완전하게 검출한다는 뜻은 아닙니다. 업로드 묶음에는 프로젝트 파일만 포함하며 기존 사용자 홈 디렉터리는 수집하지 않습니다.
