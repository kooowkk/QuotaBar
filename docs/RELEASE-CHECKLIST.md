# 실제 맥에서 확인한 뒤 배포하기

아래 항목은 완료 기록이 아니라 배포자가 체크할 목록입니다. 자동 테스트의 가짜 응답은 실제 로그인 성공 증거가 아닙니다.

- [ ] `Install.command`가 계산 검사와 SwiftUI 컴파일을 통과한다.
- [ ] 기존 설정이 유지되고 메뉴바·설정·연결 도우미가 열린다.
- [ ] 다른 기기 또는 별도 macOS 사용자에서 처음 설치 시 미연결로 시작한다.
- [ ] Claude/Codex 도구가 없으면 ‘찾지 못함’과 설치 안내를 보여준다.
- [ ] 설치 후 다시 확인하면 탐지된다. 계정 미로그인 상태를 조회 성공으로 표시하지 않는다.
- [ ] 로그인 버튼이 각각 공식 명령을 터미널에서 시작한다.
- [ ] Claude와 ChatGPT를 각자 계정으로 연결한 뒤 원본 사용량과 수치·리셋 시간이 일치한다.
- [ ] 현재·주간 값이 다를 때 두 막대가 각각 반영된다.
- [ ] 연결 실패가 0%로 표시되지 않는다. 예전 값에는 갱신 필요가 표시된다.
- [ ] 메뉴를 열어둔 상태에서도 5분 후 조회 시각이 갱신된다.
- [ ] 잠자기 해제와 재부팅 자동 실행을 확인한다.
- [ ] 라이트/다크, 강조 색상, 작은 화면에서 글자가 읽힌다.
- [ ] `Build-Release.command`가 Universal ZIP을 생성한다.
- [ ] ZIP 안 앱을 꺼내 실행해 본다. 가능하면 Apple Silicon·Intel 양쪽에서 확인한다.
- [ ] 확인하지 못한 항목과 OS/도구 버전을 릴리스 설명에 적는다.

처음에는 GitHub Release를 pre-release로 표시하세요. 다른 맥에서 테스트하지 않았다면 ‘누구나 바로 사용 가능’으로 소개하지 마세요.
