# QuotaBar — AI 구독 사용량 확인
맥 메뉴바에서 Claude와 ChatGPT 등 구독 계정의 **현재·주간 사용 한도와 리셋까지 남은 시간**을 확인합니다.

서비스마다 설정을 찾아 들어가는 대신, 상단바에서 구독 서비스의 상태를 함께 보고 싶어서 제작했습니다. 코드 작성·수정에 ChatGPT의 도움을 받았으며 계정 사용량 조회는 [CodexBar](https://github.com/steipete/CodexBar)의 CLI를 활용합니다.

**현재 버전: 0.2.0-beta.1 / macOS 14 이상 / 비공식 앱**
이 저장소는 소스 코드입니다. 배포자가 별도로 올린 앱 ZIP이 Releases에 있을 때만 미리 만들어진 앱을 받을 수 있습니다. 이번 베타의 새 UI·로그인 버튼·Universal 빌드는 macOS에서 확인이 필요합니다.

- 서비스별 `현재 사용량`, `주간 사용량`과 사용한 비율을 채운 막대
- `사용량(%) • 리셋까지 남은 시간`을 나타내는 문구
- macOS 강조 색상·라이트/다크 모드·반투명 배경
- 기본 5분 자동 조회, 접속 즉시 새로고침, 잠자기 해제 후 조회
- 설정의 연결 도우미: 필요한 도구 확인, 공식 설치 안내, 로그인 시작
- 로그인 시 자동 실행, 구독 추가·수정·삭제, 직접 입력

**퍼센트는 사용 한도 중 사용한 비율이지 정확한 토큰 개수가 아닙니다.** ChatGPT는 Codex CLI가 반환하는 계정 한도를 표시합니다. 계정에서 Work 등과 공유한다고 안내하는 경우 그 공유 한도에 해당하며, 모든 요금제의 공유 범위를 보장하지 않습니다. 일반 ChatGPT 채팅의 남은 메시지 수와 API 사용료는 표시하지 않습니다.

두 서비스는 기본 폭 354pt에서 함께 표시됩니다. 많은 항목을 추가하면 열을 늘리고 화면 공간이 부족할 때만 스크롤합니다.

## 설치하기

### 앱 ZIP이 Releases에 있는 경우

1. 이 저장소의 **Releases**에서 `QuotaBar-…-macOS-universal.zip`을 내려받습니다. `Source code (zip)`은 소스 파일입니다.
2. 압축을 풀고 `QuotaBar.app`을 응용 프로그램 폴더에 넣습니다.
3. 실행한 뒤 메뉴바의 `구독` → `구독 관리·설정` → `연결 도우미`를 엽니다.
4. 필요한 도구를 설치하고 **본인 계정**으로 로그인합니다.
5. 해당 구독을 수정해 `CodexBar 연결`을 선택하고 `저장 및 조회`를 누릅니다.

무료 배포본은 Apple Developer ID 서명·공증을 받지 않았습니다. macOS가 실행을 차단할 수 있습니다. [자세한 설치·연결 안내](docs/INSTALL.md)를 먼저 확인하세요.

### 소스만 있는 경우

`Code → Download ZIP`으로 받아 압축을 풀고 `Install.command`를 실행합니다. Apple Command Line Tools가 필요하며, 이 과정은 사용자 맥에서 앱을 만듭니다. 터미널 사용법은 [설치 안내](docs/INSTALL.md)에 있습니다.

## 필요한 외부 도구

| 사용 목적 | 필요한 것 |
|---|---|
| 두 서비스 조회 | CodexBar 앱 또는 CodexBar CLI |
| Claude 조회 | Claude Code 설치와 본인 구독 계정 로그인 |
| ChatGPT/Codex 조회 | Codex CLI 설치와 본인 ChatGPT 계정 로그인 |

외부 실행 파일이나 계정 정보를 이 저장소에 포함하지 않습니다. 도구 설치 여부와 로그인 성공 여부는 다릅니다. 사용량이 실제로 표시되어야 연결이 완료됩니다. Homebrew는 필수가 아닙니다.

## 조회 실패와 자동 갱신

연결 전·조회 실패·실제 0%를 구분합니다. 실패한 경우 이전 값을 유지하되 갱신 필요로 표시합니다. 주간 데이터가 누락되면 값을 추측하지 않습니다.

자동 조회는 **앱이 실행 중이고 맥이 깨어 있을 때** 동작합니다. 설정에서 최근 조회 완료 시각과 실패 항목을 확인할 수 있습니다. 서비스 카드에 마우스를 올리면 데이터 시각·오류를 볼 수 있습니다. 외부 도구나 서비스 변경으로 조회가 중단될 수 있습니다.

## 비용·개인정보·이용 조건

QuotaBar 자체는 무료이며 서버, 유료 API, Apple 개발자 등록 없이 로컬 빌드·공유할 수 있습니다. 사용자는 각 서비스의 이용 권한·구독을 직접 준비합니다. 외부 서비스의 요금이나 약관을 QuotaBar가 대신 보장하지 않습니다.

개발자 서버로 로그인 정보·사용량을 수집하지 않습니다. 공식 도구가 각 사용자 맥에서 인증을 관리하고, QuotaBar는 설치된 도구를 호출합니다. [개인정보 처리 설명](PRIVACY.md)을 확인하세요.

**오픈소스 라이선스와 서비스 접근 허용은 별개입니다.** 제3자 도구를 통한 자동 조회가 각 서비스에서 공식 승인됐다고 주장하지 않습니다. 계정 공유·제한 우회·과도한 호출을 위한 도구가 아닙니다. [출처·권리 검토](docs/RIGHTS.md)에 검토 범위와 남은 사항을 적었습니다.
